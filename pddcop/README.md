# PD-DCOP Materials

This folder collects reference material for a future Python implementation of
Proactive Dynamic DCOPs.

- `pddcop_jair.pdf`: JAIR paper source.
- `pddcop_jair_key_points.md`: implementation-oriented paper notes.
- `pddcop_java/`: Java project implementing the paper, kept as a reference for
  later source review.
