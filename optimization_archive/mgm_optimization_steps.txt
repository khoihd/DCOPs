## Step 3: Profile `_compute_best_value()`

Completed:

- Added `profiling/profile_mgm_compute_best_value.py`.
- The profiler builds MGM computations directly, prepares complete neighbor
  assignments, and times the actual `_compute_best_value()` path.
- It records aggregate timings for wrapped helper calls:
  `filter_assignment_dict()`, `NAryFunctionRelation.slice()`, and
  `find_arg_optimal()`.
- It also supports `--cprofile` for cumulative stack timings.

Sample runs:

- `conda run -n khoihd python profiling/profile_mgm_compute_best_value.py`
- `conda run -n khoihd python profiling/profile_mgm_compute_best_value.py --case generated --repeat 200 --neighbors 8 --constraints 24 --domain-size 8 --max-arity 4 --cprofile`
- `conda run -n khoihd python profiling/profile_mgm_compute_best_value.py --case graph-coloring --repeat 200`

Observed:

- In generated cases, `find_arg_optimal()` and repeated sliced relation
  evaluation dominate `_compute_best_value()` time.
- In the small graph-coloring case, relation slicing dominates because the
  constraints are simple and string-backed.
- `filter_assignment_dict()` is visible but small in the sampled cases.
- Relation-level helper optimization remains out of scope for this MGM pass.
- `assignment_cost()` is excluded from this pass based on its docstring: it
  intentionally remains a generic constraint loop shared by several algorithms,
  preserving missing-value fallback through `kwargs` and variable-cost
  handling.
- `find_optimal()` is excluded from this pass based on its docstring: it
  intentionally performs a generic exhaustive domain scan because arbitrary
  constraints do not expose enough structure to skip candidate values safely.

Verification:

- `conda run -n khoihd ruff check profiling/profile_mgm_compute_best_value.py`

Closure:

- `assignment_cost()` and `find_optimal()` will not be optimized as part of
  this MGM pass. Their docstrings document why they remain generic,
  behavior-sensitive relation helpers.
- If MGM is revisited later, start a new focused plan before changing message
  flow or local relation evaluation.
