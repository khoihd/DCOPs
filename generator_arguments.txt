Generator argument inventory
============================

Scope: CLI arguments registered for `pydcop generate ...` problem generators.
Most parser definitions live in `pydcop/commands/generators/`; `iot`,
`small_world`, `ising_soft`, and `mixed_problem` are wired from
`pydcop/commands/generate.py`.

Global CLI argument consumed by generators
------------------------------------------

- `--output`
  - source: `pydcop/dcop_cli.py`
  - type: str
  - required: no
  - default: None
  - note: many generators check `args.output` to write YAML files instead of stdout.

Generate command argument
-------------------------

- `-c`, `--correct_density`
  - source: `pydcop/commands/generate.py`
  - action: store_true
  - required: no
  - default: False
  - note: currently used by the older in-file mixed/graph generation paths.
